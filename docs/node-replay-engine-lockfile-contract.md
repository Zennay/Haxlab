# Node replay-engine lockfile contract

HaxLab's replay and imitation tools depend on the Node replay engine
`node-haxball`. The direct dependency is exactly pinned in `package.json`, but
reproducible installs also require npm's resolved dependency graph to be committed.

## Contract

- `package-lock.json` is generated by npm from the repository's exact
  `package.json`; dependency resolution metadata is never hand-authored.
- The lockfile root package declares the same exact `node-haxball` version as
  `package.json`.
- The resolved `node_modules/node-haxball` package has exactly that version.
- Registry resolution uses HTTPS and carries npm SHA-512 integrity evidence.
- Dependency upgrades must update `package.json`, the generated lockfile, and
  decoder provenance as one reviewable change.

The lockfile does not change the selected replay engine version. It makes fresh
installs of the existing version reproducible and reviewable.
